# デスクトップマスコットとしての Muse

このリポジトリは、デスクトップマスコットとして Muse を画面に配置し、あなたの Muse からの通信を受けてメッセージを表示するマスコットを作るためのものです。

導入は、自分の Muse にガイドをお願いし、協力して進めてください。

## 導入に使うもの

導入の過程では、以下の2つのソフトウェアのインストールが必要となります。Muse の指示と説明に従って作業を行ってください。

### SSP

マスコットを画面に表示するために使います。公式サイト「独立伺か研究施設 ばぐとら研究所」（https://ssp.shillest.net/）で、無料で配布されています。

### Tailscale

あなたの Muse からの通信を、あなたの PC まで届けるために使います。公式サイト（https://tailscale.com/download/windows）で配布されています。個人の利用は無料です。

作成したゴーストは、ご自身の環境で使うためのものです。第三者への再配布は、やめておいてください。シェルには、作成した Muse のアバターから生成した画像が含まれています。
